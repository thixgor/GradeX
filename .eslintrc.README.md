# Sobre a configuração do ESLint

O repositório não tinha `.eslintrc` — `next lint` abria um prompt interativo e,
na prática, nunca rodava. Este arquivo foi criado junto com o Manual da
Histologia para que houvesse alguma checagem possível.

Desde o Next 16 (que removeu o `next lint`) a configuração é a plana, em
`eslint.config.mjs`, e o `npm run lint` chama o ESLint direto sobre `app`,
`components` e `lib` — os mesmos diretórios que o `next lint` olhava. As regras
do React Compiler que o `eslint-plugin-react-hooks` 7 trouxe ficam desligadas;
o motivo está no próprio arquivo.

## `@next/next/no-img-element` está desligada

O acervo da Histologia tem 9.175 imagens servidas por hash a partir do Vercel
Blob. `next/image` cobraria otimização por original de até 4 MB e reencodaria
fotomicrografias — que é exatamente o que não se pode fazer com material usado
para reconhecimento morfológico. As imagens do módulo usam `<img>` com
`loading`, `decoding` e `sizes` explícitos.

## O repositório tem violações anteriores a este trabalho

Rodar `npx next lint` (hoje `npm run lint`) na árvore inteira acusa **207 violações em 93 arquivos**,
todas anteriores a esta seção. Limpá-las é trabalho à parte e não se faz
relaxando regra.

Enquanto isso, `npm run lint:histologia` checa só o módulo novo, que está limpo.
