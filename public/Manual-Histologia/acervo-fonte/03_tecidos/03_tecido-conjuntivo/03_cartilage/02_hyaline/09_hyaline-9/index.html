Capsular matrix

The matrix immediately surrounding the chondrocyte is called the capsular matrix and contains the highest glycosaminoglycan contain and thus is intensely basophilic by light microscopy. This region lacks Type II collagen fibrils but does contain other collagen subtypes.

Territorial matrix

Beyond the capsular matrix is the territorial matrix which also surrounds isogenous groups. Territorial matrix is rich in Type II collagen fibrils which do not display the banding pattern seen in Type I collagen fibrils. Territorial matrix has a lower concentration of glycosaminoglycans and thus stains less intensely.

Interterritorial matrix

Interterritorial matrix is present between isogenous groups and has a much paler, pinkish stain. The major collagen here is also Type II. This region is not present in the electron micrograph.
