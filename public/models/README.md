# Modelo 3D do coração

O Manual do Eletrocardiograma usa o arquivo `heart.glb` desta pasta como o
coração 3D (modo "Modelo 3D"), com alternância para um coração procedural.

## Atribuição (obrigatória — licença CC BY 4.0)

O modelo `heart.glb` incluído é:

- **Título:** "Realistic Human Heart"
- **Autor:** neshallads — https://sketchfab.com/neshallads
- **Fonte:** https://sketchfab.com/3d-models/realistic-human-heart-3f8072336ce94d18b3d0d055a1ece089
- **Licença:** CC BY 4.0 — https://creativecommons.org/licenses/by/4.0/
- **Modificações:** exibido em tempo real com contração, marcadores anatômicos
  e efeito de fluxo sanguíneo sobrepostos (a geometria/texturas originais não
  foram alteradas).

A licença **CC BY 4.0 permite uso comercial** desde que a atribuição acima seja
mantida. O crédito também aparece no rodapé do visualizador 3D no site.

## Trocar o modelo

Substitua `public/models/heart.glb` por outro GLB (de preferência CC0 ou CC BY,
com o devido crédito). O componente detecta e carrega automaticamente; se o
arquivo faltar, usa o coração procedural.
